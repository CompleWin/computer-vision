# Лабораторные работы по Компьютерному зрению

В папках Lab* лежат готовые лабораторные работы, в некоторых из них лежат папки explanation с .ipynb файлами, где каждая ячейка расписана.  
В папке Teacher's лежат лабораторные работы от преподавателя.

Начиная с лабораторной 4, работы выполняются в marimo. Чтобы открыть файл marimo нужно прописать в папке с файлом
```
marimo edit KZ_Lab4.py
```
Точно такой же командой можно создать файл для работы в marimo.
